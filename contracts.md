# Function contracts

This file lists the public function contracts for the modules in the architecture and the REST API routes that expose the required behavior.

| Module | Function | Signature | Success result | How it fails | Spec rule it serves | Injected |
|---|---|---|---|---|---|---|
| UserSessionAndBagIdentity | get_active_user | `get_active_user(self, user_id: str) -> str` | Returns the active user identifier for the given user context. | Raises `NotImplementedError` if the identity boundary has not been implemented. | Domain Model; FR-001; FR-003; logged-in preconditions in Scenario-001 and Scenario-002. | `user_id` passed from the request path; no clock or external service is injected in this stub. |
| UserSessionAndBagIdentity | get_bag_id_for_user | `get_bag_id_for_user(self, user_id: str) -> str` | Returns the bag identifier for the active user. | Raises `NotImplementedError` if the bag identity binding has not been implemented. | Domain Model; FR-001; FR-003. | `user_id` passed from the request path; no clock or external service is injected in this stub. |
| PhotoCaptureAndOcrIntake | capture_photo | `capture_photo(self, image_path: str) -> str` | Returns the persisted photo asset path or identifier. | Raises `NotImplementedError` if the camera or photo capture flow is not implemented. | Goal: “Support adding a disc to the user's bag via photo and OCR”; Scenario-001. | `image_path` from the client upload or camera capture; no clock is injected in this stub. |
| PhotoCaptureAndOcrIntake | infer_brand_and_name | `infer_brand_and_name(self, image_path: str) -> dict[str, str]` | Returns a dictionary containing at least `brand_name` and `disc_name` keys. | Raises `NotImplementedError` if OCR has not been implemented. | Goal: “Support adding a disc to the user's bag via photo and OCR”; Scenario-001. | `image_path` from the captured file; no OCR model or clock is injected in this stub. |
| TryDiscsCatalogLookup | find_candidate_matches | `find_candidate_matches(self, brand_name: str, disc_name: str) -> list[dict[str, str]]` | Returns candidate disc records from the TryDiscs catalog. | Raises `NotImplementedError` if the catalog lookup has not been implemented. | Goal: “Support adding a disc to the user's bag via photo and OCR and trydiscs”; Scenario-001. | `brand_name` and `disc_name` from OCR confirmation; no external catalog client is injected in this stub. |
| DiscFormEditor | build_disc_form | `build_disc_form(self, disc_id: str | None, catalog_match: dict[str, object] | None) -> dict[str, object]` | Returns a populated editable disc form payload. | Raises `NotImplementedError` if the form model has not been implemented. | FR-002; Scenario-001; Scenario-002. | `disc_id` and `catalog_match` from the selected catalog result; no clock or serializer is injected in this stub. |
| DiscFormEditor | submit_disc_form | `submit_disc_form(self, disc_id: str | None, values: dict[str, object]) -> dict[str, object]` | Returns the final approved disc record to be persisted. | Raises `NotImplementedError` if the final user confirmation flow has not been implemented. | FR-001; FR-002; Scenario-001; Scenario-002. | `disc_id` and `values` from the form; no clock or validation provider is injected in this stub. |
| BagRepository | list_disc_records | `list_disc_records(self, bag_id: str) -> list[dict[str, object]]` | Returns the full bag content for the active user. | Raises `NotImplementedError` if persistence has not been implemented. | FR-003; home screen requirement. | `bag_id` is the identity-bound bag; no storage client is injected in this stub. |
| BagRepository | add_disc_to_bag | `add_disc_to_bag(self, bag_id: str, disc_record: dict[str, object]) -> dict[str, object]` | Returns the stored disc record after insertion into the bag. | Raises `NotImplementedError` if the bag write path is not implemented. | FR-001; Scenario-001. | `bag_id` and `disc_record` from the confirmed final form; no database client is injected in this stub. |
| BagRepository | update_disc_record | `update_disc_record(self, bag_id: str, disc_id: str, updated_fields: dict[str, object]) -> dict[str, object]` | Returns the updated disc record after applying the edit. | Raises `NotImplementedError` if the update path is not implemented. | FR-002; Scenario-002. | `bag_id`, `disc_id`, and `updated_fields` from the edit request; no transaction manager is injected in this stub. |
| HomeBagView | render_home_bag | `render_home_bag(self, user_id: str) -> list[dict[str, object]]` | Returns the bag list payload for the home screen. | Raises `NotImplementedError` if the home view renderer is not implemented. | FR-003; home screen requirement. | `user_id` from the authenticated session; no UI library or renderer is injected in this stub. |
| HomeBagView | route_to_add_disc | `route_to_add_disc(self, user_id: str) -> str` | Returns the navigation target for the add-disc flow. | Raises `NotImplementedError` if the route target is not implemented. | FR-001; Scenario-001. | `user_id` from the authenticated session; no router is injected in this stub. |

# REST API contracts

| Route | Method | Function mapping | Success result | How it fails | Spec rule it serves |
|---|---|---|---|---|---|
| `/bags/{user_id}/discs` | `GET` | `HomeBagView.render_home_bag(user_id)` with `UserSessionAndBagIdentity.get_active_user(user_id)` and `get_bag_id_for_user(user_id)` guard checks | Returns the bag list payload for the home screen. | Returns `HTTP 501` with `{"error": "not_implemented", "message": "GET /bags/{user_id}/discs is not implemented."}` | FR-003; home screen requirement. |
| `/bags/{user_id}/discs` | `POST` | `BagRepository.add_disc_to_bag(bag_id, disc_record)` after resolving `bag_id` via `UserSessionAndBagIdentity.get_bag_id_for_user(user_id)` | Returns the saved disc record after the user confirms the final add-disc form. | Returns `HTTP 501` with `{"error": "not_implemented", "message": "POST /bags/{user_id}/discs is not implemented."}` | FR-001; Goal: add disc via photo and OCR; Scenario-001. |
| `/bags/{user_id}/discs/{disc_id}` | `PUT` | `BagRepository.update_disc_record(bag_id, disc_id, updated_fields)` after resolving `bag_id` via `UserSessionAndBagIdentity.get_bag_id_for_user(user_id)` | Returns the updated disc record and the user returns to the home bag view. | Returns `HTTP 501` with `{"error": "not_implemented", "message": "PUT /bags/{user_id}/discs/{disc_id} is not implemented."}` | FR-002; Scenario-002. |
